# Teaching Protocol

主题：后续模型如何按照统一蓝图继续教学、实践和记录

课程顺序、阶段和门禁以
[Production Offline RAG Course Blueprint](00-course-blueprint.md)
为准；当前坐标以 [Learning Status](00-learning-status.md) 为准。

## 1. 教学目标

最终目标不是只会读代码，而是：

1. 理解当前仓库的真实行为。
2. 在本地运行并解释关键链路。
3. 理解当前实现与生产边界的差异。
4. 按课程蓝图继续实现并通过可重复门禁。
5. 最终能够复述设计选择、故障边界和验收证据。

默认教学路径：

```text
当前实现
  -> 真实运行
  -> 结果解释
  -> 生产方案对照
  -> 用户确认
```

## 2. 教学节奏

后续模型必须：

1. 以一个行为、边界或小节为单位教学。
2. 每次只讲一个小段，讲完停下来确认理解。
3. 用户没有确认之前，不继续下一段。
4. 用户说“懂了”后，才把对应课程视为已学习。
5. 用户说“半懂”或“没懂”时，换例子、图或运行结果解释，不能只重复原话。
6. 已确认内容和新的运行证据必须回写 `docs/teaching/`。

必要时让用户用自己的话复述，但不要求每一小段都考试。

## 3. 每节课的固定结构

每节优先包含：

1. 解决什么问题。
2. 前置课程提供了什么。
3. 当前仓库如何实现。
4. 输入、输出、身份、状态和数据边界。
5. 本地如何运行。
6. 结果如何判断成功或失败。
7. 当前实现与生产做法的差异。
8. 本节验收证据。
9. 用户理解确认。

“能运行”不等于“运行正确”；必须解释为什么输出能证明对应边界。

## 4. 状态晋级

课程只使用：

- `已学习`
- `已实现待学习`
- `已规划`
- `阻塞`

晋级规则：

- 实践、测试和真实验证通过：`已规划 -> 已实现待学习`。
- 用户逐节确认：`已实现待学习 -> 已学习`。
- 外部条件缺失：进入 `阻塞`，记录原始错误、影响和解除条件。

禁止：

- 代码提交后直接标记用户已学会。
- 一节通过就把整个五节阶段标记完成。
- 用“基本完成”“大概没问题”代替门禁。
- 为了进度数字降低安全、隔离或数据完整性要求。

## 5. 蓝图顺序

开始新主题前依次读取：

1. [世界地图](../../world/game-world-map.md)
2. [完整课程蓝图](00-course-blueprint.md)
3. [当前学习状态](00-learning-status.md)
4. 当前课程 SOP 和 operation log

默认按蓝图顺序推进。只有以下证据可以调整：

- Golden Dataset 结果。
- 可复现的正确性、性能、容量或恢复故障。
- 新的安全、隐私、合规或部署要求。
- 实践证明当前前置关系无法实施。

调整时必须先更新蓝图，再同步世界地图、学习状态和接手说明。

## 6. 实践与门禁

每节实践至少留下：

- 输入 fixture 或真实请求。
- 运行命令。
- 预期结果和实际结果。
- 失败边界。
- 测试或真实服务证据。
- 当前未解决的生产差距。

L34 之后每五节组成一个阶段。阶段完成要求：

1. 五节单课门禁全部通过。
2. 阶段实践产物能够共同运行。
3. 阶段验收门禁完整执行。
4. 操作日志记录环境、命令、关键结果和已知限制。
5. 代码、SOP 和学习状态不互相矛盾。

## 7. 正确性和降级边界

当前小节必须解决：

- 影响行为正确性的问题。
- 用户、记忆和知识域隔离问题。
- 数据丢失、重复写入和非法状态转换。
- 会让验收结果失真的 Tokenizer、模型或数据版本问题。

可以进入 [优化 Backlog](00-optimization-backlog.md)：

- 尚无运行数据支持的性能优化。
- 尚无第二个真实模型时的通用抽象。
- 尚无失败样例时的复杂 Reranker 或校准。
- 不影响当前阶段门禁的便利性增强。

Backlog 不是正式课程。只有被蓝图吸收后，才可以据此开始新实践。

## 8. 文档记录

记录分为：

1. 权威蓝图：`00-course-blueprint.md`
2. 动态状态：`00-learning-status.md`
3. 单课 SOP：具体课程行为和运行方法
4. Batch Operation Log：真实批次验证证据
5. Backlog：未成熟候选和生产差距
6. Handoff：新模型最小接手入口

同一事实只保留一个权威来源，其他文档链接过去。不要在多个文件复制并分别维护课程
顺序和状态。

## 9. 当前执行点

- 教学：从 L24 开始。
- 新实践实现：从 L34 开始。
- 当前实现边界：L33。
- 当前终点：L78。

继续教学不能重复实现 L24-L33；继续新实现不能跳过 L34 的生产 Golden Dataset。
